01 · Syfte

Synliggör Draken-ärenden i ACE

När ett relevant ärende skapas eller uppdateras ska backend kunna skapa ett Work Item i ACE med rubrik, instruktion och direktlänk till ärendet i Draken.

Nytt ärende

Work Item skapas utan utpekad agent och går till den allmänna Work Item-kön.

Uppdaterat ärende

Om ärendet har en tilldelad handläggare kan dess AD-namn skickas som predefinedAgentName och kontakten läggas på handläggarens personliga kö.

03 · End-to-end-flöde

Från e-post till handläggning

EmailReader läser inkommande e-post och skapar eller uppdaterar ett ärende via SupportManagement.

SupportManagement avgör att händelsen ska generera ett Work Item.

SupportManagement skickar POST /workitem till Telia ACE WorkItem REST Proxy.

Payloaden innehåller entrance: Draken, errand: w01, instruktion och contentUrl till Draken-ärendet.

För uppdaterade tilldelade ärenden skickas även predefinedAgentName.

ACE routar kontakten till allmän eller personlig kö.

Om personlig kontakt inte hanteras inom konfigurerad tid återgår den till allmän kö. Detta konfigureras av Telia i ACE.

Handläggaren öppnar det befintliga Draken-ärendet via contentUrl.

04 · Ansvar

Vem gör vad?

1

EmailReader

Läser funktionsbrevlådor och initierar skapande/uppdatering via SupportManagement.

2

SupportManagement

Äger ärendet, avgör när Work Item ska skapas, bygger payload och anropar ACE REST API.

3

Telia ACE

Skapar kontakten, routar till allmän/personlig kö och hanterar fallback enligt ACE-konfiguration.

4

ACE Interact / Draken

Presenterar Work Item och öppnar det redan existerande ärendet i Draken. Ett nytt ärende ska inte skapas.

05 · REST API

AddWorkItem

HTTPS/JSON används mot Telias WorkItemInterfaceProxy.

Endpoint för Kontakt Sundsvall

POST https://wiproxy.ccs.teliacompany.net/wi-interface-proxy/rest/JHbKjqJt/workitem

JHbKjqJt är system-id för Kontakt Sundsvall. Anropet autentiseras med Basic Authentication.

Bekräftad payloadJSON
{
  "from": "Jeppe Jeppsson",
  "subject": "Nytt ärende i Draken",
  "entrance": "Draken",
  "errand": "w01",
  "workitem": "Öppna ärendet i Draken",
  "contentUrl": "https://draken.sundsvall.se/kontaktsundsvall/arende/KS-123456",
  "customKeys": {
    "predefinedAgentName": "jep11jep"
  }
}
Vid lyckat anrop returneras bland annat contactId och emailUid. Om referensen behöver sparas för senare operationer bör emailUid användas.

08 · Felhantering

Normala REST-fel

Status

200 lyckat · 401 autentiseringsfel · 502/503 temporära fel lämpliga för retry.

Spårbarhet

Använd Api-Version: 2 för strukturerade fel och logga Draken-ärendereferens tillsammans med ACE:s request-/incident-id.
